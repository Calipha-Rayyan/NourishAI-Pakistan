# PRD Reference

Source: AI-Powered Personalized Diet Planner PRD v1.0
Target market: Pakistan
Platform: Streamlit web application

Core MVP: collect profile + goal + dietary constraints + allergies + health considerations + cuisines + PKR budget, then generate a personalized 7-day meal plan with recipe resources.

Out of scope: calorie/macro calculations, real-time food prices, grocery delivery, accounts/login, progress tracking, wearables, medical diagnosis/treatment, medication recommendations, guaranteed outcomes, and Halal certification/verification.
